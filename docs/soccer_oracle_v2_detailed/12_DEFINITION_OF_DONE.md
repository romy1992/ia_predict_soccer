# 12 — Definition of Done

Soccer Oracle V2 è production-ready pre-match quando:
- DB canonico unico;
- import storico/oggi/futuro affidabile;
- odds snapshot timestamped;
- point-in-time dataset;
- walk-forward validato;
- 1X2 corretto;
- DC coerente;
- U/O monotono;
- calibration attiva;
- bookmaker baseline;
- backtest out-of-sample;
- model lifecycle;
- prediction ledger;
- Match Center Oracle;
- paper betting monitorato;
- test automatici critici passano.

Schedina Oracle e Live Oracle sono milestone successive.
